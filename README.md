# IBS Al-Hamra Malang - Official Website

Website resmi Islamic Boarding School (IBS) Al-Hamra Malang. Dirancang dengan desain modern, islami, elegan, dan responsif untuk memberikan informasi lengkap seputar jenjang pendidikan SMP & SMA, program unggulan, dan penerimaan santri baru (PPDB).

---

## 🌟 Fitur Utama
- **Hero Section Dinamis**: Dilengkapi background video animasi drone kampus IBS Al-Hamra (`.mp4`) dengan HTTP Range streaming support.
- **Multibahasa (i18n)**: Mendukung Bahasa Indonesia (ID), English (EN), dan Bahasa Arab (العربية).
- **Program Pendidikan Unggulan**: Jenjang SMP dan SMA dengan kurikulum komprehensif (Digital Entrepreneur, Moslem Scholar, IT Engineering).
- **Desain Modern & Elegan**: Menggunakan Bootstrap 5, palet warna bernuansa Deep Navy, Emerald Green, dan Gold Al-Hamra.
- **Local Dev Server**: Server HTTP Node.js bawaan tanpa dependensi pihak ketiga berat, mendukung video streaming HTTP 206 Partial Content.

---

## 🚀 Cara Menjalankan

1. **Clone repositori**:
   ```bash
   git clone <repository-url>
   cd "New folder (5)"
   ```

2. **Jalankan development server**:
   ```bash
   npm run dev
   ```

3. **Buka di browser**:
   Akses [http://localhost:3000](http://localhost:3000)
